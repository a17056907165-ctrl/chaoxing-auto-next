# 学习通 · 自动下一节

当前版本为 **1.5.7**。这是一个本地 Edge / Chrome 浏览器扩展。启用后可自动播放视频，滚动学习通内嵌文稿和 PPT。完成本节任务点后自动切换。空白页可直接切换，独立章节题和混排的章节题都可略过。

## 安装（以 Edge 为例）

1. 在地址栏打开 `edge://extensions`。Chrome 使用 `chrome://extensions`。
2. 从 GitHub 仓库的 **Code → Download ZIP** 下载并解压，或用 Git 克隆仓库。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压目录里的 **extension 文件夹**，也就是包含 `manifest.json` 的文件夹。
5. 刷新学习通课程页，在右下角点击“启用自动切换”。如果浏览器阻止自动播放，按面板提示点击播放。

安装后不需要运行 Python、Node，也不需要安装其他浏览器插件。登录直接使用浏览器现有的学习通登录状态。

## 使用

- 右下角面板会显示播放状态和切换状态，可随时暂停。
- “自动点击视频播放”和“视频弹题自动尝试选项”默认开启。
- 自动播放会在进入新视频时点击播放器的播放控件，必要时调用标准 HTML 视频播放功能。手动暂停后不会不断恢复；视频弹题答对并点击继续后，允许再尝试一次恢复播放。
- 同一节中向下排列的多个视频会依次播放，一次只自动启动一个，包括分布在不同播放器子页面中的视频。发现尚未加载的视频框时，扩展会滚到该播放器以触发加载。同页含文稿或 PPT 时，先播放视频，再滚动课件预览。
- 视频任务点以学习通显示的完成状态为准。重新进入本节时，已完成的视频任务点会直接跳过。普通视频可以使用当前浏览器保存的播完记录，记录按课程、班级和章节区分。播放位置由学习通播放器恢复。
- 视频弹题按页面对错反馈逐项尝试：单选和判断题尝试不同选项，多选题尝试不重复的非空组合（最多支持 6 个多选项）。答对后点击“继续播放”。没有反馈时等待并停止重复提交；遇到填写文字、次数限制或选项无法识别时显示原因。
- 学习通内嵌的文稿和 PPT 如果设有任务点，扩展会把预览框里的内容向下滚到底。课件如果继续加载后面的内容，扩展会接着滚动。等待学习通显示任务点完成后再切换。同一节的多个课件会依次处理。
- 空白页和独立章节题页在加载后直接切换。只有章节标题的页面，以及带插图的「暂无内容」页，都按空白页处理。混排的章节题可略过，其他任务点仍需完成。其他阅读内容、未知未完成任务点、尚在加载的课件和锁定的下一节会让扩展留在当前页。
- 出现“学习未完成”提示时，扩展会检查当前页是否为空白页、独立章节题页，或是否只剩章节题任务，再决定是否点击提示中的“下一节”。
- 默认开启自动倍速，目标速度为 2×。在“播放、弹题与切换设置”中可以选择 1.25×、1.5×、1.75×、2×、2.5×、3× 或 4×，选择后点击“保存设置”。
- 倍速在开始播放后优先实际尝试目标速度，面板显示当前正在播放的视频的速度。目标为 2× 时，即使菜单暂时只读到 1.5×，也不会提前降档；只有目标被拒绝或恢复后，才最多尝试一次较低菜单速度。各播放器分别判断限制，避免其他视频的菜单干扰当前视频。
- 取消勾选“自动设置倍速”并保存后不再自动修改速度；当前视频已设置的速度可以在播放器手动调整。暂停扩展会同时暂停后续的自动设置。
- “暂停自动切换”立即取消尚未发送的切换操作。
- 点击右上角 `−` 可以收起面板，点击 `+` 展开。
- 同一个标签页、同一门课跳转后会保留启用状态。新标签页或重开浏览器后需要重新启用。
- 浏览器禁止自动播放时会显示提示，不会通过强制静音或修改浏览器设置绕过限制。

## 更新桌面上已经安装的版本

如果浏览器已经加载桌面的 `extension` 文件夹，更新该文件夹后，在 `edge://extensions` 或 `chrome://extensions` 中找到“学习通 · 自动下一节”，点击该扩展的“重新加载”按钮（圆形箭头），然后刷新学习通课程页面并重新启用。无需重新选择文件夹。

## 支持范围与实际验证

适用于电脑浏览器的学习通章节页，地址路径以 `/mycourse/studentstudy` 结尾，包含常见的 `/mooc2-ans/mycourse/studentstudy` 和 `/mooc-ans/mycourse/studentstudy` 页面。

程序检查每个可访问的学习通子页面中的 HTML 视频，包括嵌套、跨学习通子域的播放器。视频章节需要整页所有检测到的视频都完成，才尝试下一节。

本版本通过页面现有控件选择和提交视频弹题，学习记录仍由平台产生。它不会修改播放位置、移除弹题来强行继续，也不会代填或提交独立章节测验。遇到平台锁定下一节、无法识别的弹题、验证码或视频错误时，需要按提示处理。

弹题行为通过 Edge 模拟课程测试验证。识别适配常见 `.ans-videoquiz`、`.ans-videoquiz-opt`、`#videoquiz-submit`、`#spanNot`、`#spanRight` / `#spanYes`、`#videoquiz-continue` 结构。不同课程可能需要根据实际弹题界面调整。

下一节识别依赖“下一节”“下一章节”等按钮文字，任务点识别适配 `.ans-job-icon` / `.ans-job-finished` 结构。如果面板未出现、不能识别按钮，或课程使用其他域名/结构，需要根据实际页面适配。也可以在设置中填写明确指向下一节按钮的 CSS 选择器。

保持浏览器开启和电脑唤醒。浏览器冻结或丢弃标签页、电脑睡眠时无法执行切换；恢复后会再次检查状态。

## 隐私与权限

扩展仅在 `chaoxing.com` 及其子域运行；设置保存在浏览器本地，启用状态保存在本次浏览器会话中。`webNavigation` 用于定位同一课程标签页的播放器子页面。没有外部脚本、统计服务、密码收集或网络上传功能。

## 开发验证

规则和消息测试覆盖空白页、章节题略过、视频和课件的任务点确认、倍速、自动播放、手动暂停和弹题恢复。Edge 模拟课程测试包含跨子域播放器、混排任务和课件预览滚动。测试默认加载项目中的 `extension` 文件夹。

复现测试：先执行 `npm install`，再执行 `npm test`。`npm run test:browser` 验证原有功能，`npm run test:questions` 验证视频弹题、纯题目页与自动播放，`npm run test:quiz-state` 检查弹题反馈慢、控件晚加载、全部组合耗尽、答对后关闭弹题等边界情况。它们使用已安装的 Edge 和独立浏览器配置，不登录或修改真实课程；结果和界面预览写入 `artifacts` 文件夹。

实现参考：[Chrome 内容脚本文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[消息传递文档](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)、[HTML 媒体播放速率标准](https://html.spec.whatwg.org/multipage/media.html#dom-media-playbackrate-dev)。
